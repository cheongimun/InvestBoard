투자자를 위한 리텐션 지표 계산 방식 상세 설명

🎯 방문자 리텐션 (Visitor Retention)

정의: 첫 방문 후 특정 일에 다시 방문한 사용자 비율

D1 = (Day+1 재방문자 / Day0 방문자) × 100

용도: 콘텐츠 매력도, 사용자 참여도 측정

💰 구매자 리텐션 (Transaction Retention)

정의: 첫 결제 후 특정 기간 내 재결제한 고객 비율

M1 = (30일 내 재결제자 / 첫 결제자) × 100

용도: 수익성, LTV 산출, 재구매율 측정

리텐션 계산 유형 비교
유형 정의 특징 사용 예
Classic (Day-N) 정확히 Day N에 복귀한 사용자 엄격함, 업계 표준 D1, D7, D30 KPI
Rolling (Unbounded) Day N 또는 그 이후 복귀한 사용자 너그러움, 장기 추적 전체 이탈률 측정
Range (Bracket) 특정 기간 범위 내 복귀 (예: 1-7일) 유연함, 커스텀 주간/월간 코호트
Full (Consecutive) 매일 연속으로 복귀한 사용자 가장 엄격 습관 형성 앱
SQL 쿼리 예시 (BigQuery)
-- D1 Classic Retention 계산
WITH user_first AS (
  SELECT session_id, MIN(DATE(created_at)) as first_date
  FROM `supabase_sync.free_saju_results`
  WHERE session_id IS NOT NULL
  GROUP BY session_id
),
d1 AS (
  SELECT DISTINCT f.session_id
  FROM user_first f
  JOIN `supabase_sync.free_saju_results` e
    ON f.session_id = e.session_id
    AND DATE(e.created_at) = DATE_ADD(f.first_date, INTERVAL 1 DAY)
)
SELECT ROUND(
  COUNT(DISTINCT d.session_id) /
  NULLIF(COUNT(DISTINCT f.session_id), 0) * 100, 2
) as d1_retention
FROM user_first f LEFT JOIN d1 d ON f.session_id = d.session_id
